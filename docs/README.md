# Tevion Documentation Map

- `PRODUCT_BRIEF.md` — product purpose, users, core experience, metrics, and risks.
- `ARCHITECTURE.md` — system boundaries, state machine, provider contract, memory isolation.
- `DECISIONS.md` — accepted architecture and product decisions.
- `PRODUCT_DEVELOPMENT_FLOW.md` — six-category operating model: Getting Started, The Main Flow, Shaping, Upkeep, Productivity Skills, Reference Skills.

Start with `PRODUCT_BRIEF.md`, then read `PRODUCT_DEVELOPMENT_FLOW.md` before creating a new product or engineering issue.
