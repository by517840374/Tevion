# Tevion 文档导航

- `PRODUCT_BRIEF.md`：产品目标、用户、核心体验、指标和风险。
- `ARCHITECTURE.md`：系统边界、状态机、Provider 契约和记忆隔离。
- `DECISIONS.md`：已经确定的产品与架构决策。
- `PRODUCT_DEVELOPMENT_FLOW.md`：六类产品开发流程：Getting Started、The Main Flow、Shaping、Upkeep、Productivity Skills、Reference Skills。

建议先阅读 `PRODUCT_BRIEF.md`，再阅读 `PRODUCT_DEVELOPMENT_FLOW.md`，然后创建新的产品或工程 Issue。

仓库根目录的 `README.md` 是中文版；`README.en.md` 是英文版。技术名词、代码标识符和文件名在必要处保留英文，方便与代码对应。
